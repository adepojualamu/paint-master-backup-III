Danger zone

Reset demo data Wipes the local seed data (jobs, customers, inventory) and restores defaults.

Production-mode status

Paint Masters runs in demo or production mode based on the <meta name="pm-mode"> tag in each HTML head. Demo seeds the customer site + admin store with sample data so the platform is browseable from day one. Production starts every store empty so the dispatcher's real entries are the only data on the platform.

Local data on this device

Each row is a localStorage key the platform writes to. Tick the rows you want to clear, then hit "Wipe selected" — local-only, the backend isn't touched.

One-click production reset

Reset to clean production state Wipes EVERY localStorage key the platform uses (customer + admin + painter), forces a fresh sign-in, and shows you the meta-tag flip required for production deployment. Use this once, before you push the site online.
